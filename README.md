# 🦊 الأجوبة الكاذبة

لعبة جماعية أونلاين باللهجة العراقية — كل لاعب يكتب جواب غلط عشان يخدع الباقين، والكل يصوت على الجواب اللي يعتقده صحيح.

## التشغيل محلياً

```bash
npm install
npm start
```

افتح `http://localhost:3000`. السيرفر يطبع رابط الشبكة المحلية بعد (مثل `http://192.168.0.114:3000`) — استخدمه حتى يدخل أصحابك من موبايلاتهم على نفس الواي فاي.

لتغيير المنفذ: `PORT=8080 npm start`

## شلون تنلعب

1. واحد يسوي غرفة → يطلعله كود من 5 محارف + رابط مشاركة.
2. الباقين يدخلون بالكود أو بالرابط، بس باسم مستعار (بدون تسجيل).
3. كل جولة، لاعب بالدور يختار فئة السؤال من 4 فئات.
4. يطلع سؤال عن معلومة غريبة → كل واحد يكتب جواب غلط (35 ثانية).
5. تنخلط كل الأجوبة الغلط مع الجواب الصحيح → تصويت (25 ثانية).
6. **النقاط:** +1 إذا اخترت الجواب الصحيح، و +1 عن كل شخص ينخدع بجوابك.
7. بالنهاية تطلع لوحة الترتيب والفايز، وخيار "العب مرة ثانية" بنفس الكود.

القوانين الكاملة موجودة داخل اللعبة نفسها (زر **اقرا القوانين الكاملة** بالصفحة الرئيسية).

## النشر على Render.com

المستودع فيه [`render.yaml`](render.yaml) جاهز، فالنشر ما ياخذ غير دقيقتين:

1. ادخل [dashboard.render.com](https://dashboard.render.com) وسجل دخول بحساب GitHub.
2. اضغط **New → Blueprint**.
3. اختار هذا المستودع. Render راح يقرا `render.yaml` تلقائياً ويعرض عليك خدمة اسمها `akadhib`.
4. اضغط **Apply** وانتظر أول بناء (~2 دقيقة).
5. راح ياخذ رابط شكله `https://akadhib.onrender.com` — هذا رابط اللعبة.

> **ملاحظة عن الخطة المجانية:** السيرفر ينام بعد 15 دقيقة خمول، وأول زيارة بعدها تاخذ ~30 ثانية لين يصحى. ولأن الغرف محفوظة بذاكرة السيرفر، إعادة تشغيله (أو النوم) تمسح أي غرفة شغالة — يعني ابدوا اللعبة بعد ما تفتح الصفحة أول مرة.

الإعدادات المهمة موجودة بـ `render.yaml`: المنطقة `frankfurt` (الأقرب للشرق الأوسط)، وفحص الصحة على `/api/health`، والنشر التلقائي مع كل `git push`.

## بنية المشروع

```
server/
  index.js        سيرفر Express + Socket.io (الأحداث والتحقق)
  game.js         محرك اللعبة: الغرف، المراحل، المؤقتات، النقاط
  questions.json  بنك الأسئلة (87 سؤال بـ 5 فئات)
public/
  index.html      كل شاشات اللعبة
  css/style.css   نظام التصميم (RTL + موبايل)
  js/art.js       الرسومات: 12 أفاتار، الماسكوت، أيقونات الفئات والواجهة
  js/app.js       منطق الواجهة والاتصال
render.yaml       إعدادات النشر على Render
```

## الإعدادات

كل الأرقام موجودة بأعلى [`server/game.js`](server/game.js) داخل `CONFIG`:

| الإعداد | الافتراضي | الوصف |
|---|---|---|
| `MIN_PLAYERS` | 3 | أقل عدد لبدء اللعبة |
| `MAX_PLAYERS` | 8 | أقصى عدد بالغرفة |
| `BLUFF_SECONDS` | 35 | وكت كتابة الجواب الغلط |
| `VOTE_SECONDS` | 25 | وكت التصويت |
| `CATEGORY_SECONDS` | 20 | وكت اختيار الفئة |
| `REVEAL_SECONDS` | 18 | وكت عرض نتيجة الجولة |
| `CATEGORY_CHOICES` | 4 | عدد الفئات المعروضة كل جولة |
| `MAX_ROUNDS` | 20 | أقصى عدد جولات |

المضيف يكدر يغير عدد الجولات ووكت الكتابة والتصويت من اللوبي مباشرة (من 10 لين 120 ثانية).
عدد الجولات الافتراضي = عدد اللاعبين (كل واحد ياخذ دور اختيار فئة مرة وحدة).

## إضافة أسئلة

زيد على [`server/questions.json`](server/questions.json) بنفس الشكل:

```json
{
  "اسم الفئة": [
    { "question": "نص السؤال؟", "answer": "الجواب الصحيح" }
  ]
}
```

**الشرط المهم:** الجواب لازم يكون معلومة غريبة/نادرة محد يعرفها أكيد — مو ثقافة عامة سهلة.

إذا أضفت فئة جديدة، زيد أيقونتها بـ `CATEGORY_ICONS` داخل `server/game.js`
والرسمة المقابلة لها بـ `ICONS` داخل `public/js/art.js`.

## التصميم

نظام تصميم بأسلوب دولينجو: خلفية فاتحة، أزرار ثلاثية الأبعاد بحافة سفلية أغمق، رسومات SVG مسطحة بطبقات وظلال ناعمة (كلها مرسومة بالكود، بدون صور خارجية)، وسُلّم مسافات وأحجام منتظم من مضاعفات 4px.

الأنيميشن: انتقالات بين الشاشات، دخول متتابع للقوائم، نبض على زر البدء لما يكتمل العدد، شريط مؤقت يتحول أحمر بآخر 5 ثواني، اهتزاز عند الخطأ، وكونفيتي عند الفوز. كل الحركات تنطفي تلقائياً إذا المستخدم مفعّل `prefers-reduced-motion`.

## الحالات المعالجة

- **انقطاع لاعب وسط اللعبة:** يضل موجود بالقائمة (باهت)، وجوابه وصوته محسوبين، ويكدر يرجع بنفس هويته إذا حدّث الصفحة.
- **طلعة المضيف:** الصلاحية تنتقل تلقائياً لأول لاعب متصل.
- **ما ضل غير لاعب واحد:** اللعبة تنتهي تلقائياً وتوديك للوحة النهائية.
- **ما كتب جواب بالوكت:** ياخذ جواب تلقائي عشوائي، وما ينطي نقاط لصاحبه حتى لو انخدع بيه أحد.
- **جوابين متطابقين:** يندمجون بخيار واحد، وكل واحد ياخذ نقطة عن كل من انخدع.
- **كتب الجواب الصحيح بالصدفة:** ياخذ +1 مباشرة وجوابه ما ينضاف للقائمة.
- **اسم مكرر بالغرفة:** ينرفض ويطلب اسم ثاني.
- **الغرف الفارغة:** تنمسح تلقائياً بعد 10 دقائق بدون لاعبين متصلين.

المؤقتات كلها محسوبة بالسيرفر وينرسل معها وكت السيرفر، فالعميل يصلّح فرق الساعة ويطلع نفس العد التنازلي عند الكل.
